Exact token counts

Anthropic does not publish an offline tokenizer for current Claude models. If you add your own API key, each message is sent once to Anthropic's free count_tokens endpoint, counted with the chat's own model, and the result is cached. Anthropic describes the result as an estimate that can differ slightly. The key stays in this browser and is only sent to api.anthropic.com. Chat text goes to Anthropic, so leave this off if you would rather it didn't.
